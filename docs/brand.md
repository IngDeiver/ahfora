# AHFORA brand

The mark combines an open geometric **A** with connected nodes. The frame suggests
an agent harness; the nodes represent specification, implementation and verification.

| Token | Color | Use |
| --- | --- | --- |
| Midnight | `#101827` | Main background and light-theme wordmark |
| Teal | `#2DD4BF` | Primary mark and connection points |
| Sky | `#60A5FA` | Secondary connection / planning accent |
| Cloud | `#F8FAFC` | Light background and dark-theme wordmark |
| Slate | `#64748B` | Supporting text on light backgrounds |

SVG assets are scalable, self-contained and have accessible titles/descriptions.
Keep the aspect ratio and sufficient empty space around the mark. The wordmark uses
system sans-serif fallbacks rather than requiring a bundled font. Assets are original
AHFORA work distributed under the repository's MIT license.
