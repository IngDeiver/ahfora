# Changelog

## 0.1.0 — Unreleased

- Visual workflow diagram covering the main orchestrator, specialists, Engram,
  user approvals, persistent project records and the correction loop.
- Interactive planner decisions: immediate blocking questions, grouped final
  confirmations, answer tracking and faithful mediated delivery when direct input is unavailable.
- Readable four-digit spec IDs with coordinated reservation and legacy identity mapping.
- User-visible spec number, title, path and phase during authoring and review.
- Mandatory responsible-role delegation, explicit capability failure reporting and
  user-approved alternatives instead of silent main-agent substitution.
- User-selected model binding for every native role and explicit QA/developer
  correction handoffs with mandatory re-verification.
- Native edit capability: OpenCode edit allow, Claude acceptEdits and Gemini
  project auto_edit, while preserving existing client settings and role boundaries.
- Automatic startup from ordinary development requests; Claude/Gemini context imports
  load the canonical AGENTS.md without a manual activation prompt.
- Dependency-free npm scaffolder for generic, Claude Code, OpenCode and Gemini CLI use.
- Canonical orchestration, constitution and explicit SDD lifecycle/approval contracts.
- Spec author, planner, developer and QA roles with sequential fallback.
- Seven portable skills covering requirements, architecture, SOLID, verification,
  maintenance, approved local improvement and the SDD workflow.
- Mandatory Engram readiness, resumable shared/local state, unique spec IDs and history.
- Non-destructive initialization, same-version reinstall, previews and adapter additions.
- Installer/contract/package tests and Linux/Windows CI configuration.
- English documentation, MIT license and original SVG identity assets.
